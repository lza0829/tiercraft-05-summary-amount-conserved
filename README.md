# 05-tiercraft（筑层）

筑层 — 数仓分层建设台：贴源入仓 → 明细清洗标准化 → 汇总落表 → 层间行数/键对账。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流按序落库，**不是** 质检隔离签发。
**也不是** 报表看板 / CRUD 后台 / 电商订单前台 / OA 工单。

## 启动

```bash
docker compose up --build
```

本地开发：

```bash
# 后端
cd backend
pip install -r requirements.txt
set DATA_DIR=..\data
uvicorn app.main:app --reload --port 10500

# 前端
cd frontend
npm install
npm run dev
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://localhost:5500 |
| 接口 | http://localhost:10500 |

## 主链

登记主题域 → 贴源层装载夹具 → 明细层清洗标准化 → 汇总层聚合 → 层间对账报告与各层列表数字同源

## 汇总守恒与快照恢复

「明细到汇总」只按业务键（业务日+门店编码）聚合。写入汇总层后立即校验：

1. **金额守恒**：汇总金额合计与本次参与聚合的明细金额合计一致。容差为绝对差 ≤ `0.000001`（`pipeline.SUMMARY_AMOUNT_TOLERANCE`），仅用于吸收二进制浮点舍入误差，会随任务报告一起展示。
2. **行数与键对账**：汇总 `line_count` 合计等于明细行数；汇总键集合与明细聚合出的键集合完全一致（不缺键、不多键）。
3. **失败恢复**：任一校验不通过则整次任务记为「失败」，该主题域汇总层恢复到任务开始前快照（`layer_summary_snapshots` 持久化保存），不留下本次写入的半截键或新旧混杂键。
4. **报告留存**：每份明细到汇总任务记录明细合计、汇总合计、漂移、容差、成败与恢复结果；数字与汇总层列表、层间对账同源，刷新/重启后仍在。

守恒失败时接口不返回错误码，而是正常返回状态为「失败」的任务记录，界面据此展示失败原因与恢复后的汇总态。
